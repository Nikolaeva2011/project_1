# WordWise Mini

**WordWise Mini** — приложение для изучения английских слов.

## Возможности

- Добавление английских слов и их переводов.
- Просмотр собственного словаря.
- Удаление слов из словаря.
- Проверка знания английских слов с помощью теста.
- Случайный выбор слов для тестирования.
- Проверка правильности введённых переводов.
- Сохранение слов в базе данных SQLite.
- Просмотр статистики и отслеживание прогресса.

## Использовали:

- Python
- PyQt6
- SQLite

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone ссылка-на-репозиторий
```

2.Установите venv и PyQt6 и активируйте их:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

3.Откройте папку с файлами проекта.
